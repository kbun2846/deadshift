deadshift alpha v0.65 is a minimalist top down western shooter with distinct weapons and explosive combat, playable in the browser on mobile or pc

- three distinct weapons: static, nominal and ballast
- online multiplayer: free-for-all for up to 4 players, join with a room code
- kill feed, scoreboard and weapon swaps between lives
- weapon tutorials
- deadwater outpost: a desert town with enterable buildings, destructible props and a crop field that burns
- touch controls with an editable layout, five graphics presets
